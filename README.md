# Bilyard Ishlab Chiqarish

Samarqanddagi bilyard va snooker stollari ishlab chiqaruvchisining sayti (UZ / RU / EN).

- Sayt papkasi: `billiard/` (oddiy HTML, CSS va JS, build kerak emas)
- Netlify: `netlify.toml` allaqachon sozlangan (`publish = "billiard"`)
- Matnlar: `billiard/js/i18n.js` (RU, EN) va `billiard/index.html` (UZ)
- Rasmlar: `billiard/img/opt/` (WebP, 480/960/1280)
