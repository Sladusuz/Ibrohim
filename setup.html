Sayt va admin panelni ulash

Mijozlar buyurtmasi admin panelga boshqa qurilmadan ham tushishi uchun bir marta, taxminan 5 daqiqa.

1Supabase loyihasi yarating

supabase.com ga kiring (bepul), New project bosing. Loyiha tayyor bo'lguncha 1-2 daqiqa kutasiz.

2Bazani tayyorlang

Supabase'da SQL Editor > New query ni oching, quyidagi tugma bilan SQL ni nusxalab qo'yib, Run bosing. (Namunaviy mahsulotlar kerak bo'lsa, ikkinchi tugmadagini ham shunday ishga tushiring.)

3Kalitlarni kiriting va tekshiring

Supabase: Project Settings > API. Project URL va anon public kalitni qo'ying. (service_role kalitni qo'ymang!)

4Sozlamani saytga qo'ying

js/config.js faylining tarkibini shu matn bilan almashtiring va saytni qayta yuklang (hosting'ga ham shuni yuklang).



  
5Admin foydalanuvchi yarating
Supabase: Authentication > Users > Add user (email va parol, Auto Confirm yoqilgan). Yaratilgan foydalanuvchining UID sini nusxalab, SQL Editor da bajaring:

    
insert into admins(user_id) values ('SHU_YERGA_UID');
Keyin admin panelga shu email va parol bilan kiring.
