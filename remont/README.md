# VIP REMONT sayti

Toshkentdagi pod klyuch remont kompaniyasi uchun statik veb-sayt (HTML, CSS, JS, kutubxonasiz).

- `index.html`, `style.css`, `script.js` — sayt
- `img/` — rasmlar (`img/stock/` — Unsplash, bepul litsenziya; qolganlari VIP REMONT Telegram kanalidan)
- Ishga tushirish: `index.html` ni brauzerda oching yoki `python3 -m http.server`
